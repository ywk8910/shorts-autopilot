최종 수정일: 2026-10-02

## 1. 개요

shorts-autopilot(이하 "본 도구")은 운영자 개인이 자신의 YouTube 채널 하나를 운영하기 위해 만든 비상업적 오픈소스 도구입니다. 제3자에게 서비스를 제공하지 않으며, 운영자 외의 이용자가 없습니다.

## 2. YouTube API 서비스

본 도구는 **YouTube API 서비스(YouTube API Services)** 를 사용합니다. 본 도구를 사용하는 것은 [YouTube 서비스 약관](https://www.youtube.com/t/terms)에 동의하는 것을 의미합니다. 개인정보 처리에 관하여는 [Google 개인정보처리방침](https://policies.google.com/privacy) 및 본 저장소의 [개인정보처리방침](privacy.html)이 적용됩니다.

본 도구가 호출하는 엔드포인트는 다음으로 한정됩니다.

- `youtube.videos.insert` — 하루 최대 1회, 운영자 본인 채널에 영상 업로드
- `youtube.channels.list` — 최초 설정 시 연결된 채널 확인

## 3. 콘텐츠와 데이터 출처

영상에 포함된 수치는 공개 데이터 출처(Frankfurter 환율 API, 공개 시장 데이터)에서 자동 수집한 것이며, 모든 화면에 출처와 기준일을 표기합니다. 정확성을 보장하지 않으며 **투자 판단의 근거로 사용해서는 안 됩니다.** 음성은 AI 합성이며 영상 설명란에 이를 명시합니다.

## 4. 면책

본 도구는 있는 그대로(as-is) 제공되며 명시적·묵시적 어떠한 보증도 하지 않습니다. 본 도구의 사용으로 발생한 손해에 대해 운영자는 책임지지 않습니다.

## 5. 변경 및 중단

운영자는 사전 고지 없이 본 도구의 동작을 변경하거나 중단할 수 있습니다. 본 약관이 변경되면 이 페이지의 최종 수정일이 갱신됩니다.
